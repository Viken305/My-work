WHICH VERSION TO USE

  Chrome    Product pages, boutique and brand sites, apps, social graphics and
            hero images. Works on dark and light backgrounds; it looks richest
            on graphite or black.

  Line      Any background and any brand colour: UI, print, engraving and
            stamping. The SVGs use currentColor, so in code they take the text
            colour of their parent; in design apps, recolour the strokes.

Both versions are plain vector (strokes, fills and gradients, no filters), so
they open cleanly in Figma, Illustrator, Sketch, Affinity Designer and Inkscape.


HOW THE CHROME IS BUILT

  Each steel rod is drawn three times: a graphite rim, a banded chrome body and
  a white specular highlight. Hands and springs use the same passes in heat-blued
  steel; jewels are ruby.
