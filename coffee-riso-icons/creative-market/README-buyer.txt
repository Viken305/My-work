COFFEE RISO ICONS
24 two-ink risograph icons for cafés, roasters and coffee apps

Thank you for your purchase!


WHAT'S INSIDE

  SVG/Textured/      24 SVGs with ink grain, halftone dots and slight misregistration
  SVG/Clean/         24 SVGs with flat fills, each ink on its own named layer
  PNG/Textured/      transparent PNGs at 512 px and 1024 px
  PNG/Clean/         transparent PNGs at 512 px and 1024 px
  Preview.html       open in any browser to see the whole set


WHICH VERSION TO USE

  Textured  Websites, menus, posters, packaging and social graphics. The texture
            is built with SVG filters, which browsers render perfectly. Design
            apps may flatten or drop the texture, so use the PNGs or the Clean
            version there.

  Clean     Figma, Illustrator, Sketch, Affinity Designer and Inkscape. Flat
            colours only. Overlaps are pre-mixed, and each ink sits on its own
            group (tint, pink, blue, blue-over-tint, blue-over-pink), so you can
            recolour one ink at a time.

GRID

  Every icon is drawn on a 200 x 200 grid with 4 px round linework, so the set
  stays consistent at any size. For small UI sizes (24-32 px), the Clean version
  reads best.
