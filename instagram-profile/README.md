## 2. Profile picture and highlight covers

### Profile picture
It shows at about 110 px on phones, inside a circle, so it has to read at a tiny size.

**Idea: a "V" monogram drawn like one of your own icons.** It uses the same stroke weight and rounded corners as your icon sets, sitting on one of your signature gradients.

- Canvas 1080 × 1080. Keep the mark inside the middle ~70% so the circle crop doesn't cut it.
- Background: one gradient you own and repeat everywhere, e.g. violet `#6C4BFF` → coral `#FF7A59`, or a warmer peach → pink.
- Mark: a white or near-black "V" (or "vs"), bold, with no thin lines.
- No text besides the letter. Check it at 40 px before you upload.
- Swap the gradient for a seasonal one for big drops if you like, but keep the "V" the same so people still recognise you.

### Highlight covers
Upload 1080 × 1920 images. Only the middle circle (about 600 px wide) shows, so put the symbol in the centre.

**Idea:** one icon per highlight, drawn in your own icon style, white on the brand gradient (or gradient-coloured line art on off-white `#F7F5F2`). Every cover uses the same stroke, the same size and the same background, so the row looks like one set.

| Highlight | Cover icon | What goes in it |
|---|---|---|
| **New** | sparkle ✦ | Latest release announcements |
| **Icons** | rounded square grid | Icon set previews |
| **Gradients** | swatch / colour drop | Gradient pack previews |
| **Fonts** | "Aa" | Type specimens |
| **Seasonal** | leaf / snowflake | Holiday and seasonal packs |
| **Illustration** | pen nib | Illustration packs |
| **Freebies** | gift | Free samples (an email-list magnet) |
| **How to use** | play triangle | Install and usage tutorials |
| **Reviews** | heart / star | Buyer screenshots, tagged work |

Keep labels to about 10 characters so they don't get cut off.

## 3. Link in bio

### Recommendation: Linktree (free plan), with Instagram's own links as backup
- Instagram lets you add up to 5 links, but only the first one shows. The rest hide behind "and 4 more", without pictures or click stats.
- A link-in-bio page shows thumbnails for each collection, counts clicks per link, and you can change it in seconds for a new drop without editing the profile.
- **Linktree** is the simplest and its free plan is enough. **Beacons** is good if you later want to sell freebies or collect emails right on the page. Either works, so pick one and stick with it.
- In Instagram, make the Linktree URL the **first** link. Add your Creative Market shop as the second native link as a fallback.

Instagram Shopping product tags don't work for Creative Market products. Instagram's commerce rules are made for physical goods sold through an approved shop, so the link in bio and Story link stickers are your main ways to send people to the shop.

### Link structure (top to bottom)
1. **🔥 NEW: [latest pack name]**: straight to that product's page. Change it with every release and pin it at the top.
2. **🍂 Seasonal drop: [season/holiday]**: the current seasonal pack, or a Creative Market collection of your seasonal items.
3. **🛍 Shop all on Creative Market**: `creativemarket.com/<your-shop>`
4. **Icons**: Creative Market collection of your icon sets
5. **Gradients**: gradient packs collection
6. **Fonts**: fonts collection
7. **Illustrations**: illustration packs collection
8. **🎁 Free sample**: the Creative Market free goods page, or an email sign-up that gives a free mini pack
9. **Bundles / best value**: bundle listings, if you have them
10. **Dribbble / Behance / Pinterest**: portfolio links (bottom of the list)

**Tips**
- On Creative Market, make public **Collections** for each category (Icons, Gradients, Fonts, Seasonal, Illustrations). Category links then go to a tidy page instead of a search.
- Add `?utm_source=instagram&utm_medium=linkinbio` to links. Linktree's click counts already show which links work best.
- Use the same thumbnail style on the Linktree page as on your highlight covers.

## 4. Content plan

### Image sizes
| Format | Size | Notes |
|---|---|---|
| Static / carousel | 1080 × 1440 (3:4) | Matches the profile grid's 3:4 crop. 1080 × 1350 (4:5) also works. Keep text away from the top and bottom ~5%. |
| Reels | 1080 × 1920 (9:16) | Keep text inside the middle 3:4 area so the grid cover isn't cut off. Pick a custom cover for every Reel. |
| Stories | 1080 × 1920 | Leave about 250 px clear at the top and bottom for the app's buttons. |

### Which format for which product
| Product | Carousel (best for saves) | Reel (best for reach) | Static post |
|---|---|---|---|
| **Icons** | Cover → full set grid → close-up at 24/48 px → icons in use (app, website, menu) → what's included → "Link in bio" | Icons popping in to music; "how this icon was made" speed-draw; Figma drag-and-drop | Single hero icon, big, on a gradient |
| **Gradients** | Cover → 6–9 swatches per slide with hex codes → gradients on mockups (phone wallpaper, poster, UI) | Slowly moving gradients timed to music; "apply in 10 s" in Figma/Photoshop | One large gradient with the pack name |
| **Fonts** | Specimen: name → full alphabet → weights → pairings → real use (logo, poster, packaging) | Letters animating in; "type your name in this font" trend; before/after headlines | A strong single word/quote set in the font |
| **Seasonal icons** | Theme cover → set → in use (cards, social posts, store banners) → "available now" | Countdown ("Christmas icons are live 🎄"); seasonal mockup montage | Seasonal teaser with the release date |
| **Illustrations** | Cover → individual pieces → close-ups / textures → mockups → file formats included | Timelapse of the drawing process; colour variations | A finished hero illustration |

### Weekly rhythm (3–4 feed posts + daily Stories)
| Day | Post |
|---|---|
| **Mon** | Carousel: product deep dive (one pack a week) |
| **Wed** | Reel: process, timelapse or "how to use" |
| **Fri** | Carousel or static: in-use mockups, tips ("5 gradient tips for UI"), or a freebie |
| **Sun** (optional) | Reel: trend audio + product montage |
| **Daily** | Stories: work in progress, polls ("which colour next?"), reshares of buyers' work, a link sticker to the current pack |

Plan in **monthly themes** and match them to the seasons. Design buyers shop **6–8 weeks before** a holiday, so make the seasonal packs early:

| Month | Seasonal focus (publish/promote) |
|---|---|
| Jan | Valentine's, Lunar New Year |
| Feb | Spring, Easter, Holi |
| Mar | Easter, Spring |
| Apr | Mother's Day, Summer |
| May | Summer, Father's Day, graduation |
| Jun | Back to school |
| Jul | Back to school, autumn |
| Aug | Halloween, autumn, Diwali |
| Sep | Halloween, Diwali, Thanksgiving |
| Oct | Christmas / holiday, Black Friday promo |
| Nov | Christmas, New Year, Black Friday / Cyber Monday |
| Dec | New Year, Valentine's |

*(It's November now, so put the Christmas, New Year and Valentine's packs live and run your Black Friday / Cyber Monday promo.)*

### How to announce a new Creative Market release
1. **Teaser, 3–5 days before:** Story close-up crops, "guess the theme" poll, countdown sticker (people tap "remind me").
2. **Sneak peek, 1–2 days before:** a Reel showing part of the pack: "Drops Thursday."
3. **Launch day:**
   - Carousel post (cover → contents → in use → what's included / file formats → "Link in bio to shop").
   - Put the product link at the top of the link-in-bio page.
   - Stories with a **link sticker** straight to the product, reshared every few hours.
   - Pin the launch post to the top of the grid. You can pin up to 3: current launch, best seller, freebie.
4. **Launch week:** a Reel showing it in use, buyer reshares, a "how to install / use" Story added to the *How to use* highlight.
5. **Save it:** add the launch Stories to the **New** highlight and to the right category highlight.

### Caption template
```
✦ NEW: Gilt Almanac Icons ✦
24 zodiac & celestial icons engraved like an old star atlas, in gold-foil and single-ink versions.

What's inside:
• 24 icons · SVG + PNG
• Gilt (gradient) and Ink (flat) versions
• Ready for Figma, Illustrator & Sketch

Perfect for: tarot & astrology brands, candle labels, packaging, social posts.

Which sign are you? 👇
🛍 Shop via the link in bio (Creative Market)

#iconset #zodiacicons #creativemarket #designresources #graphicdesign
```
- Put the hook in the **first line**, because only about 125 characters show before "more".
- Always end with a question (comments) and "Link in bio" (sales).
- Instagram now allows **at most 5 hashtags per post**. Choose specific ones: `#iconset`, `#gradients`, `#fontdesign`, `#creativemarket`, `#designassets`, `#christmasicons`, plus one about the topic.
- Write **alt text** with keywords. It helps Instagram search and accessibility.

### Ready-made first posts from this repo
- **Coffee Riso Icons** (`coffee-riso-icons/dribbble/`): the 5 shots become a 5-slide carousel. Crop/pad them from 4:3 to 3:4, and use the "Which one is your morning order? ☕" question.
- **Gilt Almanac Icons** (`gilt-almanac-icons/dribbble/`): the 5 shots become a carousel. A "find your zodiac sign" Reel fits it well.

### What to track (every month)
- **Saves and shares** for each carousel: they show which designs people want.
- **Link taps** (Instagram Insights + Linktree clicks), then Creative Market views and sales the same week.
- Do more of the format and product type with the best link taps. Drop or change whatever is in the bottom third.
